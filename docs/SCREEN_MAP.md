## Shared screen state contract

Application routes retain the existing loading and recoverable error boundaries. Synthetic lists are synchronous; no artificial spinners imply a fetch. When real services arrive, represent loading, empty, filtered-empty, denied/404, stale/conflict, offline, and retry distinctly. No-workspace and no-project states must come from verified membership results, not an unauthenticated selector. Lists currently contain three papers, two notes and four tasks, so cursor pagination is not invented. A reader page is a local typography demonstration, not a PDF URL or compiled artifact.

Project/workspace URLs continue to resolve tenant scope server-side in future phases. Library and Research navigation is visibly workspace-organized but retains project scope in URLs; Phase 01/02 may add an authorized workspace aggregate without reusing the preview as a bypass. All created local objects and transient choices are discarded when their screen unmounts. Appearance and navigation preferences alone survive reload.
