# Python and LaTeX metering

The current Atlas production architecture has no Python code runner or native TeX compiler. KaTeX remains available for rendering mathematics inside documents. Poppler in the files container only reads PDFs. The pricing catalogue and usage ledger define and enforce boundaries for an authorized future runner, while the product leaves execution unavailable.

The shared ledger records Python elapsed milliseconds with a monthly pool and plan-specific maximum for a single reservation. Paid compute lots are consumed after included minutes by earliest expiry. A provider must reserve a logical operation before dispatch using its workspace, actor and idempotency key. Settle using measured elapsed milliseconds at or below the approved reserve, release unstarted work, and reconcile uncertain termination before making held capacity available. LaTeX accounting reserves one unit per logical compile and settles it once. Identical cache hits should return the authorized cached result before reserving another compile.

To enable execution, qualify a separate sandbox host or managed runner with default-deny network, per-job filesystem, bounded CPU, memory, process count, output and build inputs, and a watchdog that kills the full process group. The runner must use scoped input/output transport without sharing Atlas database credentials or workspace files. Native TeX must use shell escape disabled and an isolated package allowlist with no dynamic network package installation. Cache keys must include source content, compiler image and compile options, and remain workspace-scoped. An authenticated dispatch integration with verified results, cancellation, utilization telemetry, stranded-job reconciliation and resource-exhaustion tests is required before either capability can be presented as available.

The resource integration test exercises both accounting meters in real PostgreSQL. It verifies the Free Python single-run boundary, elapsed settlement below the reserve, monthly exhausted and released capacity, and the LaTeX monthly limit with idempotent settlement. It deliberately does not execute user code or make claims about isolation or runtime performance.
