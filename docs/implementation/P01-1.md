## Sabit sürümler ve kaynaklar

Node 24.21.0, npm 11.19.0, Next.js/eslint-config-next 16.4.5, React/ReactDOM 19.3.1, TypeScript 6.0.3, Prisma/client/pg adapter 7.10.1, Better Auth 1.7.18, pg 8.23.1. Exact doğrudan bağımlılıklar package.json, geçişli sürümler package-lock.json içindedir; `npm ci` frozen girişidir. TypeScript 7'ye otomatik geçilmedi; bu kombinasyon gerçek build/typecheck ile doğrulanır. Projenin genel lisansı seçilmedi; doğrudan runtime paketleri MIT, Prisma ve TypeScript Apache-2.0'dır.

- [Next.js requirements](https://nextjs.org/docs/app/getting-started/installation): Node engine ve React peer aralığı registry metadata'sıyla karşılaştırıldı.
- [Next.js advisory](https://github.com/vercel/next.js/security/advisories/GHSA-pc58-hwjq-p385): etkilenen 16.4.4 ve öncesi yerine 16.4.5 seçildi; maintainer advisory listesi ve npm audit ayrıca kontrol edilir.
- [Better Auth Prisma](https://better-auth.com/docs/adapters/prisma): Prisma 8 farklı API'si adapter tarafından desteklenmediğinden açıkça Prisma 7 sabitlendi. 7.10 yeni `prisma7.config.ts` yolu kullanılıyor.
- [Better Auth advisory](https://github.com/better-auth/better-auth/security/advisories/GHSA-9hm7-xhfp-cx58): 1.7.16 öncesi etkilenen sürüm aralığı dışında 1.7.18; OAuth bu fazda açılmıyor.
- [Prisma 7 requirements](https://www.prisma.io/docs/orm/v7/reference/system-requirements): Node 24 ve Debian/OpenSSL/ARM64/AMD64 desteği kontrol edildi.
- [PostgreSQL 18.6 notes](https://www.postgresql.org/docs/release/18.6/): desteklenen 18 ailesinin güncel minor'ı kullanılıyor.

Resmi Node Docker manifest'i Linux AMD64 ve ARM64 içeriyor; platform digest'leri ve PostgreSQL 18.6 index digest'i [images.json](../../ops/images.json) içinde. Yerel gerçek test host'u macOS ARM64/Node 24.21.0, Docker Colima Linux ARM64. Diğer platformda image çalışma testi henüz yok; P01-5'te hedef CPU doğrulanacak.

## Sınırlar

Minimal App Router, TypeScript, env doğrulama, credential değerlerini loglamayan hatalar, ayrı auth Prisma factory ve cookie-cache kapalı Better Auth session entegrasyonu var. UI→server/domain/DAL yönü korunacak. Build env/DB olmadan çalışır; generation'daki geçersiz yerel URL yalnız build config'i tamamlar, runtime varsayılanı değildir. Runtime eksik env ile fail closed olur.

Kimlik modelleri ayrı `identity` şemasında; migration ve auth/runtime bağlantıları farklıdır. Bu ilk dilim auth adapter/session roundtrip smoke'udur. E-posta doğrulama/reset, generic hata cevapları ve kişisel workspace P01-2; içerik RLS ve proje yaşam döngüsü P01-3'tedir. İlk dilim üretime dağıtılmaz.
