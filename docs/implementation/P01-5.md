Migration `202611090004_operations` separates encrypted mail into `ops.mail_outbox`: auth can no longer read the queue; queue can no longer read identity/project data; runtime can enqueue in its domain transaction but cannot read outbox payloads. `atlas_backup` has read/backup privileges, BYPASSRLS and default read-only transactions; its credential is not supplied to web/mail. `atlas_lifecycle` remains NOLOGIN, callable only through fixed authorized functions. Bootstrap checks that the DB is exactly `atlas`, creates only Atlas roles, rejects unexpected existing role privileges and never rotates an existing password. The separate migrator applies reviewed files; web startup never migrates.

`/health/live` is independent of DB availability. `/health/ready` fails closed unless the expected schema revision and a current mail-worker heartbeat are present. It returns only readiness/release/revision, never connection details. Mail stops dispatching after the current bounded SMTP operation on shutdown; leases allow recovery after an unclean stop. SMTP is at-least-once, not exactly-once.

Only web gets a Coolify domain.
