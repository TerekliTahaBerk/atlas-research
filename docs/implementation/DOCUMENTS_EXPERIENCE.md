## Delivered

- One Documents list for notes and drafts: authorized title/content-fragment search, edited/title sorting, 30-row pagination with a real total, previews, rename, archive/restore and account/project-scoped return context. Legacy destination pickers retain their existing 200-item response. Rename uses the opening revision and checkpoints the change rather than silently overwriting a concurrent edit.
- A compact control row replaces controls squeezed into workspace tabs. The measured 740 px article / 660 px text width and 32 px growing title match the supplied reference. Sources, Outline, History and Related are optional; narrow screens use a focus-managed dialog. AI and document panels are mutually exclusive without changing the provider/call policy.
- Formatting remains real Tiptap editing: headings, basic marks, nested lists with Tab/Shift+Tab, links, quotes, rule, code, undo/redo and the selection toolbar. Insert is the quick block/math menu. Strict KaTeX validation retains malformed input and prevents accidental insertion; inline/block expressions are previewed, editable and preserved in saves/export. There is no execution or LaTeX compilation.
- Source search and PDF-note quotations stay in the editor rail. Insertion preserves selected writing and uses its cursor boundary. Citation metadata refreshes without changing immutable locators; clicking a citation shows provenance and the exact PDF-location link. References follow citations actually present in the tree. Existing task/discussion creation can carry a selected-passage snapshot and document backlink.
- Acknowledged autosave retains the existing user/project/document recovery key, request UUID receipts and 1.2-second debounce. Writes serialize, pending input survives failures, and export/connected actions drain pending changes first. Navigation/visibility attempts a flush. Conflicts retain local and server copies, support downloads and explicitly resume through a new checkpointed revision. History preview never replaces the current editor; restoration creates a new revision with a stable retry receipt. Transient refresh failure retains writing, while access denial clears the private surface.
- Markdown download includes the saved revision's writing, marks, math, real bibliography and citation/locator manifest; the filename comes safely from the title, and the completed revision is shown. Recovery downloads include readable reference mappings.
