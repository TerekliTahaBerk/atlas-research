Related work — sparse attention in structure prediction

3 linked papers ATL-22 · ATL-27 Feeds §2 of main.tex

Pair representations are the dominant memory cost in modern structure prediction. Every Evoformer block updates an L × L grid, so memory grows quadratically with sequence length, and targets beyond roughly a thousand residues no longer fit at batch size one Chen & Duarte, 2023.

1. Why full pair attention does not scale

Two families of fixes exist. Low-rank methods compress the grid itself; sparse methods keep the grid but restrict which entries attend. The distinction matters for long-range contacts, which low-rank factorization tends to blur while sparse patterns either keep exactly or drop entirely.

Demo Researcher    Demo Member A    Demo Member B
Kaya Lab, Department of Computational Biology
October 22, 2026
Abstract
Pair representations dominate the memory cost of structure prediction. We introduce SparseEvo, which learns block-sparse attention masks over residue pairs, reducing peak memory by 2.4× at a 0.6 point lDDT cost on long targets.
1   Introduction
Protein structure prediction models spend most of their memory on the pair representation, which grows quadratically with sequence length [1]. For targets beyond 1,024 residues this limits batch size to one on a single accelerator.
Prior work reduces this cost either by factorizing the pair grid [1] or by fixing a sparse pattern [2]. We instead learn the pattern.
2   Method
Given queries Q and keys K, we compute

where M is a learned block mask [2]. As shown by ??, routing improves recall.

Learned routing is the newest direction: it matches dense accuracy on 87% of targets at 41% of the memory, though it is not yet peer-reviewed4. Linear attention is a weak baseline for long-range couplings5.

3   Low-rank pair updates

The pair representation z ∈ ℝL×L×c is the largest activation in the network. We replace each triangular update with a rank-r factorization, so that memory scales as 𝒪(Lrc) rather than 𝒪(L²c).

With r = 32, peak memory on a 1,400-residue target falls from 61 GB to 19 GB, while lDDT drops by 1.2 points on average across long CASP14 targets. All measurements use batch size 1 and bfloat16 activations.
