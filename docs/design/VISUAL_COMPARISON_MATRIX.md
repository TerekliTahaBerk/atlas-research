## Independent automated comparison

`pnpm qa:visual` writes raw RGB mean absolute channel difference (0–255) and counts pixels differing by more than 16, separately for sidebar/header/canvas, for each of 30 original-reference/implementation pairs. There is deliberately no pass threshold: different accessibility tokens, icons, local-only copy and authored PDF text contribute to the signal. These comparisons identify regions for inspection; they do not approve the app by comparing it to itself. Signature regression snapshots then detect subsequent implementation drift.

Reference Open, Focus, Panel, Share and History are captured in both themes. The repaired implementation adds its own corresponding states and capture manifest. No required reference screen was unavailable. In-content inline AI was verified through actual selection, context attachment and local Accept/Discard; it is an interaction entry point rather than a separate full-screen mode.
