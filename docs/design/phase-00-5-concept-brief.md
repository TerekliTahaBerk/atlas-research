> Use case: ui-mockup. Create a high-fidelity full primary desktop screen design for Atlas Research OS, a calm premium academic research workspace. This is a practical Next.js React interface, all text and controls code-native. 1440x1000 composition. Warm ivory canvas #FAF9F6, sidebar #F3F2EC, text #242622, forest primary #2B7745, sage composer #E0EBD9, subtle borders #E5E3DA. Sidebar 228px wide: small original compass/asterisk mark and ATLAS wordmark, Sample workspace selector, Search with Cmd K, Home selected, Inbox; WORKSPACE: Projects, Research discovery, Paper library; ACTIVE PROJECT: Sample project selector, Overview, Documents, Tasks, Channels, Atlas AI, Manuscripts, Experiments; Settings and Preview visitor at bottom. Topbar 60px: workspace breadcrumb, small 'Design preview', theme button. Main content 48px gutters, top at 100px. Editorial serif heading 'A place for your next discovery.' supporting copy 'Pick up a thought. Follow a question. Make something new.' Top right small 'New' green button. Spacious soft-sage inline composer block: sparkle icon 'What are you exploring today?', input placeholder 'Ask Atlas anything about your research...', bottom scope 'Sample project' and 'Interactive preview', right arrow. Below composer compact quick links 'Find papers', 'Summarize a source', 'Plan research'. Then 'Continue working' with two large horizontal document cards, restrained line art paper corner icons, titles 'Literature review' and 'Research questions', type and recent edited metadata. Then two column section with 'Your projects' left: a single beautiful simple project row 'Human-centered AI', subtle square icon, description 'Understanding how people work with intelligent systems', small paper/document counts clearly marked sample. Right 'Up next': two task rows with circle status. Bottom narrow activity strip 'A connected research desk' and research paper → note → task text links. Avoid decorative imagery, fake analytics, admin dashboard metrics, gradients, giant icon shapes, clutter or OpenNote branding. Generous negative space, 13px clean sans UI (system/Inter), 40px Georgia serif headline. 8px card radius. Also include a separate readable coordinated compact document+expanded AI panel state in a second image if possible: document tree left, focused editor center, right assistant with context chips, @ and / suggestions, explicit sample cited answer. Full screen concept first, no marketing page. Preserve required wording and content hierarchy.

Result: one full primary desktop concept. Additional module compositions extend its token, typography, rail, card, and response families directly; no second generated concept was returned.
