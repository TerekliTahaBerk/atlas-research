No tests were removed. Ordinary-motion geometry assertions poll for their original exact final bounds; deterministic screenshot/axe captures use reduced motion. The transition test waits for the target module's context before typing into its shared panel. This avoids treating URL commitment as proof that a lazy module has finished mounting.

Additional production-browser spot checks: **PASS** for a long local document (450 repeated evidence sentences, unchanged article width, scrollable text and visible real selection controls) and for retaining source scroll through PDF zoom/page changes. The local results are retained in `/private/tmp/atlas-00-5b-extended.log`.

Not exhaustively automated: arbitrary document schemas, very long file names, huge compile-log fixtures, mouse drag-to-resize extremes, every outside-click/scroll combination, IME/virtual-keyboard behavior, physical phone input, and all keyboard/assistive-technology combinations. The current three-file manuscript fixtures and recorded outputs were inspected; there is no actual large compile output. These are **NOT RUN** beyond the specific evidence above and must not be represented as production integration coverage.
