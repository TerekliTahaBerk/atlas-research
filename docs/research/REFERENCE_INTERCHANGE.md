# Reference interchange mappings (A03)

All formats map to one `ReferenceRecord` (`packages/core/src/interchange.ts`). Only present values are imported or exported; nothing is inferred. Unknown types become `other` and keep the source label as `originalType`. Unsupported fields are listed by name in the preview and not imported.

| Record field                      | BibTeX/BibLaTeX                                                                                                                                                             | RIS                                                                       | CSL JSON                                                                                                      | Zotero item                                                                                               |
| --------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| type                              | entry type (article, inproceedings/conference, book, incollection/inbook, phd/masters/thesis, techreport/report, online/www, dataset; misc/unpublished + eprint → preprint) | TY (JOUR, CONF/CPAPER, BOOK, CHAP, THES, RPRT, UNPB, ELEC/WEB, DATA, GEN) | type (article-journal, paper-conference, book, chapter, thesis, report, article → preprint, dataset, webpage) | itemType (journalArticle, conferencePaper, book, bookSection, thesis, report, preprint, dataset, webpage) |
| title                             | title                                                                                                                                                                       | TI/T1                                                                     | title                                                                                                         | title                                                                                                     |
| authors / editors                 | author / editor (`and`, `Last, First`, `von` particles, `{Corporate}` literal)                                                                                              | AU/A1 / A2/ED                                                             | author / editor (family, given, literal)                                                                      | creators (author/presenter/programmer; editor/seriesEditor)                                               |
| doi                               | doi (normalized)                                                                                                                                                            | DO                                                                        | DOI                                                                                                           | DOI, or `DOI:` line in Extra                                                                              |
| issued                            | date, or year + month                                                                                                                                                       | DA, else PY/Y1                                                            | issued.date-parts / raw                                                                                       | date                                                                                                      |
| containerTitle                    | journal/journaltitle/booktitle                                                                                                                                              | T2/JO/JF/BT/JA                                                            | container-title                                                                                               | publicationTitle/proceedingsTitle/bookTitle/websiteTitle/repository                                       |
| volume / issue / pages            | volume / number, issue / pages                                                                                                                                              | VL / IS / SP–EP                                                           | volume / issue / page                                                                                         | volume / issue / pages                                                                                    |
| publisher                         | publisher/institution/school/organization                                                                                                                                   | PB                                                                        | publisher                                                                                                     | publisher/institution/university                                                                          |
| issn / isbn                       | issn / isbn                                                                                                                                                                 | SN (classified by pattern)                                                | ISSN / ISBN                                                                                                   | ISSN / ISBN                                                                                               |
| abstract, language, keywords, url | abstract, language/langid, keywords, url (http/https only)                                                                                                                  | AB/N2, LA, KW, UR                                                         | abstract, language, keyword, URL                                                                              | abstractNote, language, tags, url                                                                         |
| Atlas identity                    | `atlasid = {atlas:<id>}`                                                                                                                                                    | `ID  - atlas:<id>`                                                        | `id: "atlas:<id>"`                                                                                            | —                                                                                                         |

Not imported: notes/annotations/attachments, BibTeX `note`, `crossref` resolution, `@preamble`, Zotero relations and child items. `pages` is the work's published page range only — never evidence that a quotation appears on a PDF page; Atlas citation locators come exclusively from verified annotations or extracted chunks. Exported provider author names stay `literal` because providers supply display names, not structured family/given parts.
