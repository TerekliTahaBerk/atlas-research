# ADR 0011: Phase Delivery

Status: accepted · 2026-10-21

## Context

The vision spans high-risk research, collaboration, execution and billing.

## Decision

Gate eight phases with explicit scope, acceptance evidence and handovers; Phase 00 remains foundation only.

## Alternatives considered

Build all modules at once; prototype fake persistence and retrofit security.

## Reasoning

Early shared contracts and tenant guarantees let future sessions work independently with honest scope.

## Consequences

Future phase plans evolve through ADRs and measured requirements; unchecked tests are never complete.

## Revisit conditions

Pilot evidence changes priorities; update plans before implementation.
