# Model providers

OpenAI uses the official `openai` SDK and Responses API; Anthropic uses `@anthropic-ai/sdk` and Messages API. Both support nonstreamed generation, typed streaming, caller cancellation, 60-second timeouts, normalized errors and token usage. Structured output is validated again with Zod. Unsupported model/configuration, system messages supplied through the request, tool dispatch and custom output schemas fail before provider dispatch. Incomplete, blocked, malformed and unexpected tool responses never become successful answers. No automatic retry or fallback changes provider, model or cost. An additional Google adapter from the existing draft uses AI SDK; Google is not required for initial activation.

The operator supplies one allowlisted model and approved pricing through `ATLAS_AI_MODEL_POLICY`. There is no hardcoded production model ID or client-selected pricing. Context bounds include UTF-8 bytes, the output schema and conservative protocol overhead. Input bytes are an upper estimate, not a provider tokenizer. Provider usage is stored for generation; interrupted/unknown dispatch retains the reservation. The UI exposes the configured model and availability.

`ATLAS_AI_PAID_REQUESTS=approved` and an approved credential are necessary for external generation or embeddings. Neither is enabled by this implementation session. Standard tests intercept provider HTTP or use `ATLAS_AI_FIXTURE_ORIGIN` on loopback, guarded by an explicitly disposable database and loopback app origin. The fixture label is visible in the UI. A key alone never enables hosted AI.

API choices were checked against [OpenAI Responses migration guidance](https://developers.openai.com/api/docs/guides/migrate-to-responses), [Anthropic SDK guidance](https://platform.claude.com/docs/en/cli-sdks-libraries/overview) and [Messages streaming](https://platform.claude.com/docs/en/build-with-claude/streaming). Exact SDK versions are pinned in the package and lockfile. Account/model access, live scientific quality, pricing approval and real-provider smoke tests remain external activation gates.
