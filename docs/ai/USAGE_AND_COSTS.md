# Usage and cost controls

All prices are approved server configuration in integer micro-USD per million tokens. No subscription price or inferred provider tariff is presented. `ATLAS_AI_MONTHLY_LIMIT_MICROS` is a deployment ceiling (1–10,000,000 micro-USD). The same ceiling also checks actor/organization/workspace/project attribution; it is intentionally conservative rather than separate billing entitlements. The UI displays recorded monthly project/actor estimates, including uncertain dispatches.

`ai_usage` is one unique actor/operation reservation-and-settlement record. Generation reserves input context maximum plus output maximum before dispatch. Query and document embeddings reserve their UTF-8 byte upper estimate before external calls. A database advisory lock serializes reservations across replicas and prevents concurrent cap bypass. Generation permits at most two active runs per actor and one per conversation. HTTP rate limits add 12 submissions per minute and the existing write/read buckets.

Known completion records actual input/output token counts on the run and settles once. Undispatched failures/cancellation release the generation reservation. Dispatched cancellation, timeout, network loss or unknown completion retains the whole reservation; stale runs reconcile conservatively and never automatically retry. Embedding amounts remain conservative estimates, including interrupted batches, rather than claims of exact provider billing. Old incomplete standalone reservations retain their estimated charge when reconciled. Operator/provider invoice reconciliation is required to establish actual billing after uncertain calls.

Caps are estimated monetary limits, not exactly-once external charging. Provider-enforced output limits and no automatic retries prevent ordinary overrun; a provider billing anomaly needs operational investigation. The initial schema records detailed generation tokens, and embedding operation cost/model lineage through the immutable indexed chunk/job, not a complete embedding invoice/token export. Large-scale budgets, distinct tenant subscription tiers and performance telemetry remain later operational work.
