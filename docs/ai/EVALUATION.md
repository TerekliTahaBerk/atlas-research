# AI evaluation and evidence

Ordinary CI makes no paid model calls. Unit contract tests feed intercepted HTTP to the official SDKs. The loopback browser fixture emits synthetic JSON/SSE and deterministic word-hash vectors; these are explicitly test outputs, never a scientific model benchmark. Integration tests use PostgreSQL 17, pgvector and non-owner application/worker logins. Browser tests use real disposable GoTrue and Storage, with scanner/extraction verdicts supplied through their authenticated protocols. Offline parser smoke tests separately exercise real Poppler with networking disabled.

Coverage includes exact quotes/UTF-16 offsets, fabricated sources, abstract page absence, malformed output, unsolicited tools, limits, cancellation/timeouts, provider failure, index dedup/revisions, source filtering, private notes, tenant denial, revocation, persistence, idempotency and concurrent reservations. The browser journey exercises saved-paper mentions, indexing, streamed citations, Reader navigation, shared modes, history recovery, cancellation and project reset. Preserve the existing preview visual baselines; unrelated worktree navigation changes must not be accepted by updating snapshots.

Adversarial source text asks to reveal another tenant or mutate permissions. Tests establish that scope/schema/tool authorization cannot be obtained through this text. They do **not** establish semantic instruction-following or scientific claim support in an actual paid model.

A real-provider evaluation is opt-in after credential, model, data policy and total spend approval. Use public/synthetic evidence only at first. Evaluate comparison attribution, unsupported claim rate, scientific entailment, prompt injection, empty context, long/multilingual excerpts, truncation and cancellation billing. Cap both per-request maximum and total operations, record only safe metrics, and reconcile invoices. No real-provider evaluation or live hosted AI test was performed in this session.
